# Estratégias e níveis de teste na prática

Laboratório acadêmico de Engenharia de Software dedicado à modelagem de estratégias e níveis de teste em um sistema fictício de GPS/GNSS.

## Sobre o projeto

O material documenta 13 abordagens distribuídas entre testes de unidade, integração, validação e sistema. Cada cenário apresenta uma explicação técnica e diagramas que identificam componentes, dependências, stubs, drivers e sistemas externos.

O domínio GPS/GNSS é fictício e foi escolhido apenas para contextualizar os exemplos. O repositório contém documentação e fontes de diagramas; não há implementação de software ou suíte de testes executável.

## Conteúdo

- `atividade/README.md`: relatório principal com as explicações dos cenários.
- `atividade/diagramas/mermaid/`: diagramas Mermaid incorporados ao relatório.
- `atividade/diagramas/plantuml/`: versões PlantUML dos diagramas.
- `atividade/prompts_utilizados.md`: registro dos prompts utilizados na atividade.
- `lab2.md`: enunciado e contexto do laboratório.

## Como consultar

Comece pelo [relatório do laboratório](atividade/README.md). Os arquivos Mermaid e PlantUML podem ser abertos individualmente em ferramentas compatíveis para inspeção ou edição.

## Tecnologias e notações

- Markdown
- Mermaid
- PlantUML
- UML e modelagem de arquitetura

## Contexto

Este repositório representa um exercício acadêmico de documentação, análise de estratégias de teste e modelagem técnica. Ele não deve ser interpretado como um sistema GPS implementado ou como evidência de testes executados em uma aplicação real.
